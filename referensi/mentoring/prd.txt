# Hello Mind — Game Design Concept (Chapter 1)

> **High‑level**: Chapter 1 memandu pemain membangun *first line* perawatan diri: mengenali emosi, coping dasar, pola pikir, dan kompas nilai — lewat 5 mini‑game arcade yang singkat (2–7 menit), aman, dan sepenuhnya bisa dimainkan **tanpa** tugas dunia nyata. Mode IRL (opsional) tetap tersedia bagi pengguna yang menginginkan translasi ke kehidupan sehari-hari.

---

## 1) Visi & Pilar Desain

**Visi:** Memperkenalkan kesehatan mental dengan cara playful, singkat, dan berbasis keterampilan (skill‑building) — fokus pada **awareness → regulation → reflection**.

**Pilar:**

1. **Therapeutic-by-design**: setiap interaksi menguatkan skill (CBT/BA/mindfulness/ACT).
2. **No shame, no grind**: waktu singkat, streak fleksibel (skip token), tidak menghukum.
3. **Privacy-first**: tidak wajib cerita personal; semua konten bisa generik.
4. **Accessible & local**: Bahasa Indonesia, metafora lokal, UI kontras tinggi, mobile‑first.

**Player fantasy:** “Aku bisa menamai emosiku, menata pikiranku, dan memilih langkah kecil yang masuk akal — semuanya dari dalam game.”

---

## 2) Struktur Game (Chapter 1)

**Hub:** layar peta tematik “Lab Hello Mind” (gaya pixel‑arcade neon). Tiap ruang = 1 mini‑game.

* **Exercise 1 — Guardian Setup** (Safety Kit)
* **Exercise 2 — Emotion Alchemist** (Hello, Me)
* **Exercise 3 — Thought Boss Rush** (Pattern/ABC)
* **Exercise 4 — Values Forge** (Initials)
* **Exercise 5 — Compassion Courier** (Snail Mail)
* **Bonus — Safe Use Guide** (artikel interaktif)

**Session target:** 1–2 ruang per sesi, durasi 5–10 menit.

**Gating ringan:** Selesaikan 3 ruang apa pun → buka lencana “Hello Mind L1”.

---

## 3) Mini‑Game Detail

### 3.1 Guardian Setup (Safety Kit)

**Tujuan:** Menyiapkan *safety concepts* dan *quick‑access* coping tanpa perlu data pribadi.

**Mode:**

* **Arcade (in‑app only)**: pemain menyusun *loadout* krisis berupa 3 teknik grounding + 1 tombol bantuan. Semua *placeholder* (tidak perlu nama/kontak nyata).
* **IRL (opsional)**: form aman untuk mengisi kontak darurat/lokasi aman — disimpan terenkripsi lokal/cloud.

**Core loop (3–5 mnt):**

1. Pilih **3 kartu teknik**: 5‑4‑3‑2‑1, napas 4‑4‑6, *cold splash* (simulasi), *body scan* 60 dtk.
2. **Trial** singkat 20–30 dtk per teknik (animasi ritme/step‑by‑step).
3. Simpan sebagai **Loadout** (ikon cepat di header game).

**Skor/Reward:** +XP untuk uji teknik; lencana “Prepared L1”.

**UI singkat:** Grid kartu teknik → tap kartu untuk demo → tombol “Add to Loadout”. Header selalu memiliki tombol **❗ Crisis** yang membuka sheet bantuan (hotline/faq).

---

### 3.2 Emotion Alchemist (Hello, Me)

**Tujuan:** Melatih *emotion labeling* & granularitas.

**Core loop (2–3 mnt):**

1. Campur 2–3 **essence** (cemas/sedih/marah/malu/kecewa/lelah) hingga total 100%.
2. Sistem menghitung koordinat **Valence‑Arousal** → tampilkan **3 label emosi terdekat** (mis. gelisah, murung, kesal).
3. Pilih label → jalankan mini‑intervensi **in‑app** (napas 4‑4‑6 45 dtk / *focus pop* 30 dtk / reframe 1‑kalimat 30 dtk).
4. Rating *ketegangan* sebelum→sesudah.

**Skor/Reward:** granularitas↑ & konsistensi label = XP; buka “resep emosi” baru.

**UI singkat:** Mixer slider → kartu label saran + definisi → tab intervensi dengan timer ring.

---

### 3.3 Thought Boss Rush (Pattern/ABC)

**Tujuan:** Mengenali distorsi & membangun reframe realistis (CBT).

**Core loop (3–5 mnt, 4 ronde):**

1. **Serangan bos**: Pikiran otomatis generik (tema akademik/sosial/kerja).
2. **Counter** 3 langkah: pilih **distorsi** → centang **bukti pro/kontra** → edit **reframe ≤120 char**.
3. **Damage & feedback**: HP bos turun sesuai kualitas reframe (jelas, berbukti, nada realistis).
4. **Refleksi mini**: intensitas emosi 0–10 sesudah reframe.

**Skor/Reward:** akurasi distorsi + reframe “baik+” memberi combo; dapat kartu “skill CBT”.

**UI singkat:** HP bos + indikator ronde; kartu pikiran; 3 tab aksi (Distorsi/Bukti/Reframe) + tombol “Luncurkan Counter”.

---

### 3.4 Values Forge (Initials)

**Tujuan:** Menemukan 2–3 nilai utama & membuat motto singkat sebagai kompas.

**Core loop (2–4 mnt):**

1. Pilih **2–3 nilai** dari daftar (integritas, kebaikan, keberanian, keluarga, pembelajaran, dll.).
2. Mini‑puzzle **“kombinasi kata”** untuk merakit **motto ≤12 kata** (mis. “IK: *Jujur, belajar, dan bantu sesama*”).
3. Simpan sebagai **banner profil**; opsional set sebagai *in‑app reminder* (toast di hari tertentu) — tanpa izin OS/IRL.

**Skor/Reward:** +XP dan lencana “Values L1”.

**UI singkat:** List nilai (chip) → kanvas perakitan motto (drag teks) → preview banner.

---

### 3.5 Compassion Courier (Snail Mail)

**Tujuan:** Melatih *self‑compassion* dengan format terstruktur.

**Core loop (3–5 mnt):**

1. Template 3 paragraf: **Aku melihat… Aku paham… Aku mendukungmu dengan…**
2. Pemain isi **dengan kalimat generik** (bisa pilih dari variasi aman — tidak wajib cerita personal).
3. Simulasi “kirim ke masa depan”: surat masuk **in‑app mailbox** 7 hari kemudian (scheduler lokal). Opsi tambahan: *mailto:* ke email sendiri (opt‑in).

**Skor/Reward:** +XP; lencana “Kind to Self”.

**UI singkat:** Editor 3 blok + *preview* surat; tombol “Jadwalkan ke Kotak Masuk (7 hari)”.

---

### 3.6 Bonus — Safe Use Guide

Artikel interaktif singkat: kapan perlu bantuan profesional, cara pakai fitur dengan aman, etika jurnal & privasi. Diakhiri kuis 3 soal; lulus → +XP kecil.

---

## 4) Progression, Ekonomi, & Retensi

* **XP** dari skill actions (bukan sekadar login). Level akun membuka kosmetik (tema arcade, skin bos, frame banner).
* **Koin** untuk dekor UI (tanpa lootbox/gacha). Semua kosmetik bisa dicapai tanpa bayar.
* **Streak sehat**: target 5 dari 7 hari/minggu; dapat **skip token** otomatis 1×/minggu.
* **Season** 6–8 minggu: Chapter 1 = Season 1 (Hello Mind). Event mingguan tematik (mis. “Deadline Week buff” di Boss Rush).
* **Achievements** aman: “Label Pro (10 label spesifik)”, “Calm Combo (3 reframe ‘baik+’ beruntun)”.

---

## 5) UX, Visual, & Aksesibilitas

**Gaya:** pixel‑arcade modern, gelap nyaman dengan aksen **indigo/emerald**. Micro‑feedback lembut (shake HP bos, confetti kecil).

**Pola layar umum:**

* **Header**: judul + **❗Crisis** + XP bar kecil.
* **Konten**: kartu besar (teks stimulus), tab aksi jelas.
* **Footer**: *helper text* & CTA utama.

**A11y:** font ≥16px, kontras >4.5:1, semua aksi dapat keyboard/tap, *reduced motion* toggle, *color‑blind safe*.

---

## 6) Keamanan & Etika

* **Crisis button** selalu terlihat; daftar bantuan lokal; *soft gate* bila rating distres ≥9 berulang → rujukan profesional.
* **Privasi default:** semua konten bisa generik; bila user menulis pribadi, data dienkripsi; *share* nonaktif secara default.
* **No dark patterns:** tidak ada penalti keras untuk absen; tidak memaksa notifikasi.

---

## 7) Telemetri & Sukses Metrik (MVP)

* **Engagement**: sesi/minggu, durasi median, penyelesaian mini‑game.
* **Skill proxy**: akurasi distorsi (Boss Rush), granularitas label (Alchemist), penurunan ketegangan median (sebelum→sesudah intervensi).
* **Retention**: D7/D28 ≥ 25–35% (target realistis awal).
* **Safety signal**: frekuensi distress tinggi → intervensi rujukan.

---

## 8) Arsitektur Teknis (stack kamu)

**Frontend:** React + Tailwind + shadcn/ui + Framer Motion.
**Backend:** Laravel (API), **Supabase** (auth + DB + row level security).

**Tabel inti (ringkas):**

* `users(id, locale, consent_flags, created_at)`
* `sessions(id, user_id, started_at, ended_at, kind)`
* `alchemist_sessions(id, user_id, va_x, va_y, tension_before, tension_after, xp_gain)`
* `boss_rounds(id, session_id, thought_text, user_distortion, reframe_text, score)`
* `values(id, key, label)` + `user_values(user_id, value_key)` + `mottos(user_id, text)`
* `letters(id, user_id, body, scheduled_at, delivered_at, delivery_channel)`
* `loadout(id, user_id, technique_keys[])`

**API (contoh):**

* `POST /alchemist/mix` → input essence → return 3 label kandidat.
* `POST /boss/round` → simpan distorsi/bukti/reframe → return score & damage.
* `POST /values` → simpan pilihan nilai & motto.
* `POST /letters` → jadwalkan surat ke mailbox in‑app (7 hari).
* `POST /loadout` → simpan 3 teknik grounding.

**Keamanan:** RLS per user, enkripsi di rest, audit log minimal, *feature flag* untuk IRL mode.

## 10) (Opsional) Web3 Aman — *Off by default*

* **SBT Wellness Badges** non‑transferable (mis. “Hello Mind L1”).
* **EAS Attestation** untuk integritas konten (hash modul v1.0 ditinjau ahli).
* **Gasless mint** via Account Abstraction; tidak ada PII/hasil klinis di on‑chain.

## 11) QA & Edge Cases

* Offline/latensi tinggi: semua mini‑game bisa jalan lokal; sinkronisasi saat online.
* Perangkat low‑end: aset ringan, lazy load, matikan efek berat.
* Teks peka: filter kata keras; opsi *content warnings*.
* Pengguna di bawah umur: IRL mode disembunyikan; komunitas dimatikan secara default.

## 12) Lampiran Konten

**Distorsi contoh:** all‑or‑nothing, overgeneralization, mind‑reading, catastrophizing, should statements, personalization.

**Nilai contoh:** Integritas, Kebaikan, Keluarga, Pembelajaran, Kesehatan, Tanggung jawab, Kreativitas, Keberanian.

**Label emosi contoh:** Gelisah, Panik, Murung, Kesal, Marah besar, Kecewa, Putus asa, Terganggu, Canggung, Pasrah, Tenang.

**Template surat (3 blok):**

* *Aku mendukungmu dengan…* (niat bantuan realistis, satu kalimat)

## 13) Phaser.io Integration (Implementation Draft)

> Target: gunakan **Phaser 3** untuk mini‑game yang butuh animasi/reaksi cepat (arcade feel), sementara layar teks/form tetap di **React**. Hasilnya: performa ringan, integrasi mudah dengan Laravel/Supabase, dan aksesibilitas terjaga.

### 13.1 Arsitektur Hibrida (React ↔ Phaser)

* **React Shell (Tailwind/shadcn)**: navigasi, header **❗Crisis**, artikel/teks, form aman.
* **Phaser Canvas**: scene arcade (Emotion Alchemist visual, Boss Rush battle, Focus Pop, Breathe).
* **Bridge**: event bus sederhana.

  * Dari Phaser → React: `window.dispatchEvent(new CustomEvent("game:session_end", {detail:{kind,score}}))`
  * Dari React → Phaser: panggil method scene aktif via ref.
* **Persistensi**: setelah sesi, React memanggil API Laravel → Supabase (`/alchemist/mix`, `/boss/round`, dsb). Phaser hanya memegang state *sementara*.

```
[React Page]
  ├─ Header (Crisis, XP)
  ├─ <PhaserCanvas scene="BossRush" onEnd={saveToAPI} />
  └─ Footer (helper)
```

### 13.2 Pemetaan Scene ke Exercise (Chapter 1)

* **Guardian Setup** → React UI (kartu loadout) + **Phaser: demo teknik** (animasi 5‑4‑3‑2‑1, napas 4‑4‑6).
* **Emotion Alchemist** → **Phaser Scene `AlchemistScene`** (mixer visual, partikel) + mini‑intervensi (Breathe/Focus/Reframe).
* **Thought Boss Rush** → **Phaser Scene `BossRushScene`** (HP bar, serangan teks, counter animasi).
* **Values Forge** → React untuk pemilihan nilai + **Phaser: kanvas motto** (animasi banner singkat) opsional.
* **Compassion Courier** → React editor; Phaser tidak wajib.
* **Safe Use Guide** → React artikel interaktif.

### 13.4 Alur Data (Laravel/Supabase)

1. Phaser menjalankan sesi → emisi event `game:session_end` (skor, durasi, meta).
2. React listener menangkap event → `fetch('/api/sessions/finish', { body: JSON.stringify(payload) })`.
3. Supabase menyimpan `sessions`, `rounds`, `alchemist_sessions`, dsb (skema di Bagian 8).

### 13.5 Asset Pipeline

* **Atlas**: `ui.atlas.json` (HP bar, tombol, ikon emosi/nilai), `boss.atlas.json` (pose bos).
* **Audio**: SFX ringan (bleep/click/soft whoosh). Volume default kecil; *mute toggle*.
* **Font**: bitmap font atau webfont (preload di BootScene).
* **Ukuran**: jaga total asset < 2–3 MB untuk first load.

### 13.6 Scene Skeleton (TypeScript)

**React wrapper**

```tsx
import { useEffect, useRef } from 'react';
import Phaser from 'phaser';

export function PhaserCanvas({ scene }: { scene: string }) {
  const ref = useRef<HTMLDivElement>(null);
  const gameRef = useRef<Phaser.Game>();
  useEffect(() => {
    if (!ref.current || gameRef.current) return;
    gameRef.current = new Phaser.Game({
      type: Phaser.AUTO, parent: ref.current, backgroundColor: '#0a0a0a',
      scale: { mode: Phaser.Scale.FIT, autoCenter: Phaser.Scale.CENTER_BOTH, width: 720, height: 1280 },
      scene: [BootScene, AlchemistScene, BreathScene, FocusPopScene, BossRushScene]
    });
    return () => gameRef.current?.destroy(true);
  }, []);
  useEffect(() => {
    const g = gameRef.current; if (!g) return;
    g.scene.stop(); g.scene.start(scene);
  }, [scene]);
  return <div id="phaser-root" ref={ref} className="w-full h-[80vh] rounded-2xl overflow-hidden"/>;
}
```

**AlchemistScene (VA mixing + label saran)**

```ts
type Point = { v:number; a:number };
const EMO: Record<string, Point> = {
  cemas:{v:-0.6,a:0.6}, sedih:{v:-0.7,a:-0.4}, marah:{v:-0.6,a:0.7},
  malu:{v:-0.5,a:0.3}, kecewa:{v:-0.5,a:-0.1}, lelah:{v:-0.2,a:-0.6}
};
const LABELS: Record<string, Point> = {
  gelisah:{v:-0.5,a:0.5}, panik:{v:-0.8,a:0.9}, murung:{v:-0.7,a:-0.4},
  kesal:{v:-0.4,a:0.5}, marah_besar:{v:-0.7,a:0.8}, kecewa_lbl:{v:-0.5,a:-0.1},
  putus_asa:{v:-0.8,a:-0.6}, terganggu:{v:-0.3,a:0.2}, canggung:{v:-0.4,a:0.3},
  pasrah:{v:-0.4,a:-0.5}, tenang:{v:0.6,a:-0.6}
};

export class AlchemistScene extends Phaser.Scene {
  weights: Record<string, number> = { cemas:40, sedih:30, marah:30 };
  constructor(){ super('Alchemist'); }

  create(){
    // UI minimal: tiga slider (garis + knob)
    const mkSlider = (x:number,y:number,key:string)=>{
      const line = this.add.rectangle(x,y,400,6,0x333333).setOrigin(0.5);
      const knob = this.add.circle(x-200+(this.weights[key]/100)*400, y, 14, 0x6d28d9).setInteractive({draggable:true});
      this.input.setDraggable(knob);
      knob.on('drag', (_p:Phaser.Input.Pointer, nx:number)=>{
        const clamped = Phaser.Math.Clamp(nx, x-200, x+200);
        knob.x = clamped;
        this.weights[key] = Math.round(((clamped-(x-200))/400)*100);
        this.renderVA();
      });
      this.add.text(x-240,y-14,key.toUpperCase(),{fontSize:'14px'});
    };
    mkSlider(360, 420, 'cemas');
    mkSlider(360, 500, 'sedih');
    mkSlider(360, 580, 'marah');

    this.add.text(360, 660, 'Lanjut → Beri Nama', {fontSize:'18px'})
      .setOrigin(0.5).setInteractive().on('pointerup', ()=> this.showSuggestions());

    this.renderVA();
  }

  private mixVA(){
    const sum = Object.values(this.weights).reduce((a,b)=>a+b,0)||1;
    let V=0,A=0; for(const [k,w] of Object.entries(this.weights)) { const e=EMO[k]; V+= (w/sum)*e.v; A+= (w/sum)*e.a; }
    return {V,A};
  }

  private showSuggestions(){
    const {V,A} = this.mixVA();
    const dist = (p:Point)=>Math.hypot(V-p.v, A-p.a);
    const sorted = Object.entries(LABELS).sort((a,b)=>dist(a[1])-dist(b[1])).slice(0,3);
    // tampilkan tombol kandidat
    let y=760; sorted.forEach(([key,p])=>{
      this.add.text(360,y, `${key.replace('_',' ')}  (${dist(p).toFixed(2)})`, {fontSize:'18px'})
        .setOrigin(0.5).setInteractive().on('pointerup', ()=> this.startIntervention(key));
      y+=48;
    });
  }

  private renderVA(){
    // radar mini: titik bergerak sesuai VA
    if (!this.data.get('vaDot')){
      const box = this.add.rectangle(360,300,160,160,0x111111).setStrokeStyle(1,0x444444);
      const dot = this.add.circle(360,300,6,0x22c55e);
      this.data.set('vaBox',box); this.data.set('vaDot',dot);
    }
    const dot = this.data.get('vaDot') as Phaser.GameObjects.Arc;
    const {V,A} = this.mixVA();
    dot.x = 360 + V*70; dot.y = 300 - A*70;
  }

  private startIntervention(labelKey:string){ this.scene.start('Breath', { labelKey }); }
}
```

**BreathScene (4‑4‑6)**

```ts
export class BreathScene extends Phaser.Scene {
  duration = { inhale:4000, hold:4000, exhale:6000 };
  create(data:{labelKey:string}){
    const c = this.add.circle(360, 640, 40, 0x22c55e);
    const cycle = async ()=>{
      await this.tweenPromise(c, { scale: 1.8, duration: this.duration.inhale });
      await this.tweenPromise(c, { scale: 1.8, duration: this.duration.hold });
      await this.tweenPromise(c, { scale: 1.0, duration: this.duration.exhale });
    };
    let loops = 3; const run = async ()=>{ while(loops--) await cycle(); this.finish(); };
    run();
  }
  tweenPromise(obj:Phaser.GameObjects.GameObject, cfg:Phaser.Types.Tweens.TweenBuilderConfig){
    return new Promise(res=> this.tweens.add({ ...cfg, targets: obj, onComplete:()=>res(null) }));
  }
  finish(){
    window.dispatchEvent(new CustomEvent('game:session_end', { detail: { kind:'breathe', seconds: 3*14 } }));
    this.scene.start('Alchemist');
  }
}
```

### 13.7 Aksesibilitas & Kinerja

* **Reduced motion**: matikan partikel & kurangi tween (respect prefers-reduced-motion).
* **Kontras** tinggi; ukuran teks ≥16 px (bitmap font besar).
* **Mobile**: batasi listener sentuh; kecilkan draw calls; batch dengan atlas.
* **Offline**: preload kritikal; gunakan Service Worker (React side) untuk cache asset.

### 13.8 Build & Testing

* **Build**: Vite + `@types/phaser` + TS.
* **Lint**: ESLint + strictNullChecks.
* **E2E**: Playwright (klik target, ukur latensi input → frame time), FPS budget ≥ 50.

```tsx
import { useEffect, useState } from 'react';
```

### 14.12 `src/components/PhaserCanvas.tsx`

```tsx
import { useEffect, useRef } from 'react';
import Phaser from 'phaser';
import { BootScene } from '../scenes/BootScene';
import { AlchemistScene } from '../scenes/AlchemistScene';
import { BreathScene } from '../scenes/BreathScene';
import { FocusPopScene } from '../scenes/FocusPopScene';
import { BossRushScene } from '../scenes/BossRushScene';

export function PhaserCanvas({ scene }: { scene: string }) {
  const ref = useRef<HTMLDivElement>(null);
  const gameRef = useRef<Phaser.Game>();

  useEffect(() => {
    if (!ref.current || gameRef.current) return;
    gameRef.current = new Phaser.Game({
      type: Phaser.AUTO,
      parent: ref.current,
      backgroundColor: '#0a0a0a',
      scale: { mode: Phaser.Scale.FIT, autoCenter: Phaser.Scale.CENTER_BOTH, width: 720, height: 1280 },
      physics: { default: 'arcade', arcade: { debug: false } },
      render: { pixelArt: true, roundPixels: true },
      fps: { target: 60, forceSetTimeOut: true },
      dom: { createContainer: true },
      scene: [BootScene, AlchemistScene, BreathScene, FocusPopScene, BossRushScene]
    });
    return () => gameRef.current?.destroy(true);
  }, []);

  useEffect(() => {
    const g = gameRef.current; if (!g) return;
    // stop semua & start yg diminta
    g.scene.getScenes(true).forEach(sc => g.scene.stop(sc.scene.key));
    // pastikan Boot pernah jalan untuk preload, lalu start target
    if (!g.scene.isActive('Boot')) g.scene.start('Boot');
    setTimeout(()=> g.scene.start(scene), 50);
  }, [scene]);

  return <div ref={ref} className="w-full h-[78vh] rounded-2xl overflow-hidden bg-neutral-950 border border-neutral-800"/>;
}
```

### 14.15 `src/scenes/AlchemistScene.ts` (Mixer VA + saran label)

```ts
import Phaser from 'phaser';

type P = { v:number; a:number };
const EMO: Record<string,P> = {
  cemas:{v:-0.6,a:0.6}, sedih:{v:-0.7,a:-0.4}, marah:{v:-0.6,a:0.7},
  malu:{v:-0.5,a:0.3}, kecewa:{v:-0.5,a:-0.1}, lelah:{v:-0.2,a:-0.6}
};
const LABELS: Record<string,P> = {
  gelisah:{v:-0.5,a:0.5}, panik:{v:-0.8,a:0.9}, murung:{v:-0.7,a:-0.4},
  kesal:{v:-0.4,a:0.5}, marah_besar:{v:-0.7,a:0.8}, kecewa_lbl:{v:-0.5,a:-0.1},
  putus_asa:{v:-0.8,a:-0.6}, terganggu:{v:-0.3,a:0.2}, canggung:{v:-0.4,a:0.3},
  pasrah:{v:-0.4,a:-0.5}, tenang:{v:0.6,a:-0.6}
};

export class AlchemistScene extends Phaser.Scene {
  weights: Record<string, number> = { cemas:40, sedih:30, marah:30 };
  vaBox?: Phaser.GameObjects.Rectangle; vaDot?: Phaser.GameObjects.Arc;

  constructor(){ super('Alchemist'); }

  create(){
    this.cameras.main.setBackgroundColor('#0a0a0a');
    this.add.text(360, 80, 'Emotion Alchemist', { fontSize:'22px', color:'#fff' }).setOrigin(0.5);
    this.add.text(360, 114, 'Campur 2–3 essence hingga 100%', { fontSize:'14px', color:'#aaa' }).setOrigin(0.5);

    // VA preview
    this.vaBox = this.add.rectangle(360, 260, 160, 160, 0x111111).setStrokeStyle(1,0x444444);
    this.vaDot = this.add.circle(360, 260, 6, 0x22c55e);

    const mkSlider = (x:number,y:number,key:string)=>{
      const line = this.add.rectangle(x,y,420,6,0x333333).setOrigin(0.5);
      const knob = this.add.circle(x-210+(this.weights[key]/100)*420, y, 14, 0x6d28d9).setInteractive({draggable:true});
      this.input.setDraggable(knob);
      knob.on('drag', (_p:Phaser.Input.Pointer, nx:number)=>{
        const clamped = Phaser.Math.Clamp(nx, x-210, x+210); knob.x = clamped;
        this.weights[key] = Math.round(((clamped-(x-210))/420)*100); this.renderVA();
      });
      this.add.text(x-240,y-14,key.toUpperCase(),{fontSize:'14px', color:'#ddd'});
      return { line, knob };
    };

    mkSlider(360, 440, 'cemas');
    mkSlider(360, 520, 'sedih');
    mkSlider(360, 600, 'marah');

    this.add.rectangle(360, 700, 280, 44, 0x4338ca).setInteractive()
      .on('pointerup', ()=> this.showSuggestions());
    this.add.text(360, 700, 'Lanjut → Beri Nama', { fontSize:'16px' }).setOrigin(0.5);

    this.renderVA();
  }

  private mixVA(){
    const sum = Object.values(this.weights).reduce((a,b)=>a+b,0)||1; let V=0,A=0;
    for(const [k,w] of Object.entries(this.weights)) { const e=EMO[k]; V+= (w/sum)*e.v; A+= (w/sum)*e.a; }
    return {V,A};
  }
  private renderVA(){
    const {V,A} = this.mixVA();
    if(this.vaDot){ this.vaDot.x = 360 + V*70; this.vaDot.y = 260 - A*70; }
  }
  private showSuggestions(){
    const {V,A} = this.mixVA(); const dist=(p:P)=>Math.hypot(V-p.v, A-p.a);
    const sorted = Object.entries(LABELS).sort((a,b)=>dist(a[1])-dist(b[1])).slice(0,3);
    let y=770; this.add.text(360, 736, 'Pilih label terdekat:', {fontSize:'14px', color:'#aaa'}).setOrigin(0.5);
    sorted.forEach(([key,p])=>{
      const btn = this.add.rectangle(360,y,300,40,0x14532d).setInteractive().on('pointerup',()=>this.startIntervention(key));
      this.add.text(360,y, `${key.replace('_',' ')}  (${dist(p).toFixed(2)})`, {fontSize:'16px'}).setOrigin(0.5);
      y+=52;
    });
  }
  private startIntervention(labelKey:string){ this.scene.start('Breath', { labelKey }); }
}
```

```ts
import Phaser from 'phaser';
export class BreathScene extends Phaser.Scene {
  duration = { inhale:4000, hold:4000, exhale:6000 };
  constructor(){ super('Breath'); }
  create(data:{ labelKey?: string }){
    this.cameras.main.setBackgroundColor('#07130b');
    this.add.text(360, 120, 'Breathe 4‑4‑6', { fontSize:'22px' }).setOrigin(0.5);
    const c = this.add.circle(360, 640, 40, 0x22c55e);
    const guide = this.add.text(360, 720, 'Hirup…', { fontSize:'18px', color:'#aaffc3' }).setOrigin(0.5);

    const cycle = async ()=>{
      guide.setText('Hirup…'); await this.tween(c, { scale: 1.8, duration: this.duration.inhale });
      guide.setText('Tahan…'); await this.delay(this.duration.hold);
      guide.setText('Hembus…'); await this.tween(c, { scale: 1.0, duration: this.duration.exhale });
    };

    let loops = 3; const run = async ()=>{ while(loops--) await cycle(); this.finish(); };
    run();
  }
  tween(target:Phaser.GameObjects.GameObject, cfg:Phaser.Types.Tweens.TweenBuilderConfig){
    return new Promise(res=> this.tweens.add({ ...cfg, targets: target, onComplete:()=>res(null) }));
  }
  delay(ms:number){ return new Promise(res=> setTimeout(res, ms)); }
  finish(){
    window.dispatchEvent(new CustomEvent('game:session_end', { detail: { kind:'breathe', seconds: 3*14 } }));
    this.scene.start('Alchemist');
  }
}
```

```ts
import Phaser from 'phaser';
export class FocusPopScene extends Phaser.Scene {
  score = 0; timeLeft = 30_000; lastSpawn = 0; spawnEvery = 900; targetKey = '◎';
  constructor(){ super('FocusPop'); }
  create(){
    this.cameras.main.setBackgroundColor('#0a0a0a');
    this.add.text(360, 80, 'Focus Pop — Tap target ◎', { fontSize:'20px' }).setOrigin(0.5);
    this.score = 0; this.timeLeft = 30_000; this.lastSpawn = 0;
  }
  spawn(){
    const x = Phaser.Math.Between(80, 640); const y = Phaser.Math.Between(200, 1150);
    const good = Math.random() < 0.6; const txt = this.add.text(x, y, good?this.targetKey:'○', { fontSize:'28px' }).setOrigin(0.5);
    txt.setInteractive({ useHandCursor: true }).on('pointerdown', ()=>{
      if (good) { this.score += 100; txt.setTint(0x22c55e); } else { this.score = Math.max(0, this.score-50); txt.setTint(0xef4444); }
      this.tweens.add({ targets: txt, alpha: 0, duration: 200, onComplete:()=>txt.destroy() });
    });
    this.tweens.add({ targets: txt, alpha: 0, delay: 700, duration: 300, onComplete:()=>txt.destroy() });
  }
  update(t:number, dt:number){
    this.timeLeft -= dt; if (this.timeLeft <= 0) return this.finish();
    if (t - this.lastSpawn > this.spawnEvery) { this.lastSpawn = t; this.spawn(); }
  }
  finish(){
    window.dispatchEvent(new CustomEvent('game:session_end', { detail: { kind:'focus', score: this.score, seconds: 30 } }));
    this.scene.start('Alchemist');
  }
}
```
